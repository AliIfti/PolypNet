How PolypNet Works

Six AI stages run automatically on every uploaded colonoscopy image.

✓
01

Validation

Heuristic + CNN check ensures the image is a valid colonoscopy frame before processing begins.

◈
02

CLAHE Enhancement

Contrast Limited Adaptive Histogram Equalisation amplifies subtle mucosal structures.

⬡
03

YOLO Detection

YOLOv11 localises polyps with bounding boxes and confidence scores in real time.

⊞
04

CNN Classification

Ensemble of VGG16, ResNet50, EfficientNetB0 and InceptionV3 classifies Benign vs Malignant.

◉
05

Segmentation

Attention U-Net produces pixel-perfect masks highlighting the polyp region.

✦
06

Clinical Report

VLM generates a structured clinical assessment including size, morphology and recommendations.
